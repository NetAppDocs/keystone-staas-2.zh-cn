= Keystone 的运营模式
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
NetApp Keystone 可通过 Keystone Storage-as-a-Service（STaaS）和 Keystone XaaS 订阅产品提供。Keystone STaaS 支持合作伙伴运营和客户运营的运营模式，而 Keystone XaaS 则由 NetApp 合作伙伴独家提供。您的产品和运营模式决定了谁来管理您的存储环境、处理日常运营并提供支持。



[[keystone-staas-operational-models]]
== Keystone STaaS 运营模型

Keystone STaaS 运营模型定义了 NetApp、合作伙伴和客户在整个服务生命周期中的责任。以下各节介绍了合作伙伴运营和客户运营的模式。



[[partner-operated-model]]
=== 合作伙伴经营模式

合作伙伴可以作为服务提供商或经销商提供 Keystone STaaS。责任取决于您与合作伙伴的协议。请联系您的服务提供商或合作伙伴，了解他们为您处理哪些任务。

*服务提供商*：服务提供商为其最终客户运营服务。作为与 NetApp 签约的一方，服务提供商负责管理多租户环境。每个租户都是服务提供商的客户，并且拥有单独的订阅，由服务提供商直接计费。服务提供商管理员负责执行租户的所有管理任务。*经销商*：作为经销商，合作伙伴充当 NetApp 与客户之间的桥梁。合作伙伴向最终客户销售 Keystone 服务并管理发票。虽然由合作伙伴负责计费，但 NetApp 会为客户提供直接支持。Keystone 支持团队与客户互动，并处理租户的所有管理任务。



[[customer-operated-model]]
=== 客户运营模式

在客户运营模式中，您根据您的存储需求和选定的性能服务级别订阅 Keystone STaaS。NetApp 定义架构和产品，并在您的本地部署存储。

您的存储和 IT 团队负责管理基础架构。您组织中的管理员为环境中的用户执行管理任务。根据您的合同，您可以向 NetApp 或您的服务提供商提交服务请求。

[[keystone-xaas-partner-delivery-and-support]]
== Keystone XaaS 合作伙伴交付和支持

Keystone XaaS 是 NetApp Keystone 下的一项独立订阅服务，由 NetApp 合作伙伴独家提供。合作伙伴为最终客户提供服务，并管理支持和日常运营。

如果您使用 Keystone XaaS，请联系您的直接合作伙伴以获取服务和支持。上面的 Keystone STaaS 运营模型和客户操作责任表未描述 Keystone XaaS 的责任。
