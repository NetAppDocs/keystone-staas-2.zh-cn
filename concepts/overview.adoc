= 了解NetApp Keystone
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
NetApp Keystone 是一个提供 Keystone 存储即服务 (STaaS) 的平台，这是一种现收现付订阅产品，适用于偏好运营费用消耗而非前期资本支出或租赁的企业。



[[keystone-staas-offering-and-services]]
== Keystone STaaS 产品和服务

Keystone STaaS 为采购、部署和管理存储基础设施提供了类似于公有云的模型。当您订阅 Keystone STaaS 时，您可以选择满足您要求的数据存储类型和性能服务级别。

Keystone STaaS 是定义如何交付和使用存储功能的产品。服务是该产品提供的功能，基本订阅中包括标准服务，而当您需要其他功能时可以购买附加服务。例如，高级数据保护（ADP）是为支持的配置提供同步站点到站点镜像的附加服务。

这种区别有助于您了解订阅中包括哪些功能以及哪些功能需要额外购买。有关标准服务和附加服务的信息，请参见 link:../concepts/supported-storage-services.html["Keystone STaaS 服务"]。



[[storage-flexibility-and-operational-models]]
== 存储灵活性和运营模式

Keystone STaaS 支持多种数据存储类型和性能服务级别。您可以从本地存储开始，并在需求发生变化时添加云服务。容量调整和云重新分配取决于您的订阅条款。

Keystone STaaS 可以在合作伙伴运营或客户运营的模式下运行。有关详细信息，请参见 link:../concepts/operational-models.html["Keystone中的运营模型"]。



[[key-benefits-of-keystone-staas]]
== Keystone STaaS 的主要优势

* *成本效益*：获得承诺容量的可预测成本，以及超出该承诺的基于使用量的消耗费用。
* *资本效率*：无需大量前期投资即可访问企业存储。
* *可扩展性*：随着业务增长增加存储容量。
* *灵活性*：调整您的存储计划，并在适当时将工作负载迁移到云。
* *云集成*：在单个订阅下使用本地和云服务。
* *安全*：通过高级安全措施和恢复功能保护您的数据。
